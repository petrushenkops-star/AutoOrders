# Автосигналы — Android

Актуальная версия: **0.5.9** (`versionCode = 32`).

## Сайт

Новый адрес, предоставленный пользователем:
**https://pbeaocuec.com/ru/futures?name=BTC/USDT&tabName=FUTURES**

Встроенный WebView использует `SiteConfig.HOME_URL`. Разрешён только HTTPS-хост `pbeaocuec.com` без поддоменов. Сайт не загружается автоматически при запуске приложения — для открытия требуется явное согласие после предупреждения.

**ВНИМАНИЕ:** домен создан 31 октября 2026 года, и независимые сервисы сообщают о рисках, включая возможный фишинг. До независимого подтверждения владельца сайта **финансовые операции в приложении отключены** (`SiteConfig.AUTO_TRADING_ENABLED = false`; проверка в UI, торговой сессии и контроллере). Не вводите пароли, торговые коды или финансовые данные на новом сайте до его проверки.

## Изменения версии 0.5.9

- Разрешены HTTPS-вложенные переходы WebView (ограничение домена сохранено для основной страницы), разрешены сторонние cookies, не ослабляется проверка TLS.
- Старый скрипт скрытия окна, созданный для предыдущего сайта, отключён для нового домена.
- «Главная» открывает корень сайта; «Браузер» открывает прямую ссылку в браузере Android. Добавлена диагностика HTTP, сбоев WebView, перенаправлений и проблем с инициализацией SPA.
- Автоматические финансовые операции остаются отключёнными до независимой проверки сайта.

## Изменения версии 0.5.8

- Изменены стартовая страница и разрешённый хост без сохранения старого домена.
- Обрабатывается прямой маршрут BTC/USDT Futures с параметрами `name` и `tabName`.
- При нажатии вкладки «Сайт» показывается предупреждение; нет автоматической загрузки непроверенного домена при старте.
- Запуск финансовых заказов заблокирован, пока сайт не пройдёт проверку.
- Сохранены прежний `applicationId`, данные, сертификат подписи, Telegram и расписание.

## Возможности и ограничения

- Предыдущий механизм ручного ввода кода и проверки статуса сохранён, но временно заблокирован для непроверенного домена.
- Telegram TDLib для чтения сообщений при наличии авторизации пользователя и личных `api_id` / `api_hash`.
- Поиск по расписанию выполняется, пока приложение открыто. Получение сообщения Telegram само по себе не запускает финансовый заказ.
- Во время вручную запущенного заказа можно использовать Android Picture-in-Picture для сохранения видимости сайта. Полноценная работа на заблокированном экране не подтверждена.

## Сборка и обновления

Исходники приложения: `max-signal-copy/project` в ветке `max-signal-copy`. Workflow: `.github/workflows/maxcopy-android.yml`.

Для сохранения обновлений поверх установленной версии **не меняются**:

- `applicationId = "com.example.maxsignalcopy"`
- постоянный сертификат подписи (секрет GitHub Actions `AUTOORDERS_SIGNING_BUNDLE`)
- существующие ключи настроек и защиты от повторного выполнения

Техническое старое название в идентификаторе пакета намеренно сохранено для совместимости и не отображается как название приложения.

Устанавливайте только подписанные APK из GitHub Releases. Проверка на реальном Android-устройстве необходима. Настройка Telegram: [TELEGRAM-SETUP.md](TELEGRAM-SETUP.md).
