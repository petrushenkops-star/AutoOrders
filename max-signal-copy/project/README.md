# Автосигналы — Android

Текущая версия: **0.5.4** (versionCode 27).

## Назначение

Работа с цифровыми кодами и пользовательскими заказами на lxcompintb.com. Подключение Telegram TDLib для чтения сообщений и настройка недельных интервалов поиска. Ручной ввод кода и проверка статуса заказа сохраняются.

## Изменения версии 0.5.4

- Пользовательское название приложения: **Автосигналы**.
- Переименовано служебное уведомление о выполняющемся заказе.
- Удалены неиспользуемые обработчики сообщений прежнего мессенджера.
- Telegram, недельное расписание, ручной ввод, история и защита от повторной отправки при неизвестном результате сохраняются.
- Технические идентификаторы пакета, сохранённых настроек и постоянная подпись оставлены без изменения, чтобы можно было установить APK поверх 0.5.3.

## Особенности работы

Telegram-поиск работает только после авторизации Telegram с собственными api_id и api_hash. Расписание поиска в текущей реализации выполняется, пока приложение открыто. Считывание Telegram не запускает финансовый заказ автоматически.

Во время вручную начатого заказа foreground service и мини-окно Android (PiP) помогают продолжить обработку при переключении на другие приложения. Надёжность работы с заблокированным экраном не подтверждена.

Для обновления устанавливайте только подписанный release APK из GitHub Releases. Проверка на реальном устройстве обязательна. Debug APK не подходит для обновления поверх подписанной версии.

## Сборка и обновления

Исходники приложения: `max-signal-copy/project` в ветке `max-signal-copy`.

GitHub Actions: `.github/workflows/maxcopy-android.yml`.

- `applicationId = "com.example.maxsignalcopy"` не изменять.
- Постоянный ключ подписи хранится в секрете GitHub Actions `AUTOORDERS_SIGNING_BUNDLE` — не размещать его в коде или сообщениях.
- Для следующего выпуска увеличивать оба значения `versionCode` и `versionName`.
- Старые технические наименования `maxsignalcopy` в пространстве имён и ключах сохранения оставлены специально для совместимости.

Историю прежних версий можно посмотреть в Git-коммитах, а настройку Telegram — в `TELEGRAM-SETUP.md`.
