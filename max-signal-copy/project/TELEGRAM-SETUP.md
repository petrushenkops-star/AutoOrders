# Telegram в приложении «Автосигналы»

Для доступа к Telegram требуется собственный `api_id` и `api_hash`, полученный через Telegram, а также авторизация на телефоне.

1. Заполните реквизиты Telegram API в настройках приложения.
2. Авторизуйтесь в Telegram, выберите нужный чат и тему «Сигнал».
3. Укажите дни недели и интервалы времени.
4. Используйте «Проверить текущее окно (БЕЗ заказа)» для проверки чтения сообщений.

**Ограничения:** Telegram сейчас используется для поиска и проверки сообщений. Полученный код сам по себе не запускает финансовую операцию. Поиск по расписанию требует открытого приложения и подключения Telegram. Работа с заблокированным экраном не подтверждена.

Не публикуйте свои ключи Telegram в GitHub и не отправляйте их в чаты.
