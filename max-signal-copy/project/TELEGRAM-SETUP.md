# Недельное расписание Telegram, версия 0.4.6

В «Настройки → Расписание поиска Telegram» выберите дни недели, начало и конец в HH:mm, нажмите «Добавить интервал». Несколько интервалов для одного дня разрешены, если они не перекрываются. Удаляйте отдельные интервалы кнопкой «Удалить». Только после добавления включайте галочку «Автоматически искать код по расписанию (БЕЗ заказа)».

Поиск выполняется в открытом приложении не чаще раза в две минуты для активного интервала. Требуется авторизация Telegram через TDLib. При найденном коде приложение лишь показывает результат диагностики, не отправляя торгового заказа. Текущая версия НЕ работает в фоне или с заблокированным экраном. Для подтверждения реального чтения истории требуются собственные `api_id` и `api_hash` Telegram.

# MAX Автосигналы 0.4.0 — Telegram / стадия чтения

Источник: обычный аккаунт Telegram → точное название группы **КОМАНДА** → точная тема **Сигнал**.

- Подключена TDLib из `io.github.tdlib-android:core:0.1.1` (Maven Central).
- `api_id` и `api_hash` вводятся пользователем в приложении; `api_hash` защищён Android Keystore и не попадает в GitHub.
- Пользователь авторизуется телефоном, кодом Telegram, при необходимости паролем 2FA.
- После входа проверка находит единственный чат с названием «КОМАНДА» и единственную тему «Сигнал», извлекает доступную историю по страницам и ищет код за выбранную дату/время.
- В интерфейсе показывается только наличие кода и его последние 2 цифры. Просмотр сообщений не отправляет никаких заказов.
- Ограничения: требуется зарегистрировать собственное Telegram API приложение в `my.telegram.org`, и доступ к теме от данного аккаунта. Для группы с несколькими одноимёнными чатами или темами автоматический выбор блокируется.
- TDLib может возвращать только доступную текущему аккаунту историю. Реальная работа чата не проверялась без авторизации пользователя.
- **Автоматический запуск финансовых операций из Telegram отключён.** Проверка чтения должна быть подтверждена на устройстве до следующего этапа.
- Автоматизация ручного заказа и уведомление «Заказ в ожидании» не менялись. MAX авто-поиск при обновлении выключается.
- Работа с заблокированным экраном не реализована.
- Для релизной установки поверх прежней версии используется прежний applicationId `com.example.maxsignalcopy` и та же постоянная подпись из защищённого GitHub Actions секрета.
