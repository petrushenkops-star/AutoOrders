# Автозаказы (AutoOrders)

Android-приложение для недельного расписания заказов на lxcompintb.com. Первый этап — тестовая версия 0.1.0, без автоматической отправки реальных финансовых заявок по умолчанию.

## Импорт исходников и сборка APK

Загрузите в корень этого репозитория файл `AutoOrders-0.1.0-source.zip` **без распаковки** через GitHub **Add file → Upload files → Commit changes**. Workflow `Import and build AutoOrders` автоматически распакует проект, добавит исходники и подготовит отладочный APK в разделе Actions → Artifacts, если тесты и сборка пройдут.

Затем последующие сборки запускаются workflow `Android APK` на вкладке Actions.

### Ограничения

Драйвер сайта экспериментальный: интерфейс личного кабинета недоступен для независимой проверки. Реальные финансовые заявки не подтверждены тестированием. В приложении изначально включён тестовый режим.

Новый цифровой код вводится вручную для каждого заказа; не вводите его в репозиторий, issue или журналы CI.
