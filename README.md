# Автозаказы (AutoOrders)

Android-приложение для расписания заказов на lxcompintb.com. Автоматизация реальных финансовых операций не подтверждена тестами на живом сайте.

## Постоянная подпись (начиная с 0.1.11)

**Подпись:** SHA-256 `ED:F5:BA:9D:66:32:E9:4F:BB:80:27:1D:44:77:75:E3:1B:C1:7B:0F:5C:59:58:92:3B:AB:1B:B9:BF:01:BA:69`.

Один раз создать Actions secret **`AUTOORDERS_SIGNING_BUNDLE`** и вставить в поле Secret значение из личного файла `AutoOrders-GitHub-Secret.txt`. Этот секрет содержит постоянный PKCS12-keystore, пароль и псевдоним ключа. Никогда не добавлять его в репозиторий, чат или issue. Сохранить отдельно резервную копию signing key.

GitHub Actions workflow `Build AutoOrders` тестирует проект и собирает debug-версию. При наличии указанного секрета он также собирает release APK, проверяет SHA-256 сертификата и публикует `AutoOrders-<version>-signed.apk` в Releases.

Чтобы запустить после добавления секрета: Actions → Build AutoOrders → Run workflow. Для каждого нового выпуска повышать **versionCode и versionName** в `app/build.gradle.kts`. Файлы существующих релизов не перезаписываются.

**Однократный переход:** APK до 0.1.10 подписаны автоматически созданным отладочным ключом среды сборки. Обновить их поверх без исходного старого ключа, вероятно, невозможно: потребуется **один раз удалить установленную версию**, что приведёт к потере локальных настроек. Начиная с установленного APK 0.1.11 с постоянной подписью, будущие версии с тем же ключом и повышенным versionCode смогут обновляться без удаления.

**Не теряйте секрет/резервную копию ключа:** иначе новые APK нельзя будет установить поверх существующих.

## Функциональность

Недельное расписание, ручной ввод нового кода перед каждым заказом, журнал заказов, встроенный браузер и диагностический режим. Работа с реальными финансовыми заказами экспериментальная.
