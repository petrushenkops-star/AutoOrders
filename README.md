# Автозаказы (AutoOrders)

Android-приложение для расписания заказов на lxcompintb.com. Автоматизация реальных финансовых операций не подтверждена тестами на живом сайте.

## Версия 0.1.29 — проверка устойчивости найденного исправления

- После успешного испытания 0.1.28 на настоящем сайте добавлена отдельная кнопка «Тест 10 секунд» во встроенном браузере и «Проверка устойчивости (10 секунд)» на экране «Сайт».
- Новый режим временно восстанавливает высоту диалога по содержимому и поднимает его над затемнением. Затем проверяет кнопку сразу, через 0,5, 2, 5 и 10 секунд; прекращает проверку при исчезновении окна, смене адреса или возвращении перекрытия.
- По окончании, при любой успешной или неуспешной проверке, приложение пытается восстановить исходные CSS-стили. Встроенное окно диагностики блокирует случайные касания элементов сайта во время проверки.
- Существующий двухсекундный тест сохранён. В отчёте каждого режима остаются временные отметки и результат отката.
- Финансовая автоматизация не изменена. Этот выпуск не нажимает «Подтв.», не вводит код и не отправляет заказ. Отдельно добавлены проверки устойчивости, смены DOM и безопасности.

## Версия 0.1.28 — временное исправление высоты окна

- Никаких нажатий на «Подтв.», кодов, отправки заказов и автоматических повторов нет. Работоспособность на настоящем сайте пока не подтверждена.
- Сохраняется прежняя только читающая диагностика «Тест окна», добавлены автоматические тесты временного исправления и отката.

## Постоянная подпись (начиная с 0.1.11)

**Подпись:** SHA-256 `ED:F5:BA:9D:66:32:E9:4F:BB:80:27:1D:44:77:75:E3:1B:C1:7B:0F:5C:59:58:92:3B:AB:1B:B9:BF:01:BA:69`.

Один раз создать Actions secret **`AUTOORDERS_SIGNING_BUNDLE`** и вставить в поле Secret значение из личного файла `AutoOrders-GitHub-Secret.txt`. Этот секрет содержит постоянный PKCS12-keystore, пароль и псевдоним ключа. Никогда не добавлять его в репозиторий, чат или issue. Сохранить отдельно резервную копию signing key.

GitHub Actions workflow `Build AutoOrders` тестирует проект и собирает debug-версию. При наличии указанного секрета он также собирает release APK, проверяет SHA-256 сертификата и публикует `AutoOrders-<version>-signed.apk` в Releases.

Чтобы запустить после добавления секрета: Actions → Build AutoOrders → Run workflow. Для каждого нового выпуска повышать **versionCode и versionName** в `app/build.gradle.kts`. Файлы существующих релизов не перезаписываются.

**Однократный переход:** APK до 0.1.10 подписаны автоматически созданным отладочным ключом среды сборки. Обновить их поверх без исходного старого ключа, вероятно, невозможно: потребуется **один раз удалить установленную версию**, что приведёт к потере локальных настроек. Начиная с установленного APK 0.1.11 с постоянной подписью, будущие версии с тем же ключом и повышенным versionCode смогут обновляться без удаления.

**Не теряйте секрет/резервную копию ключа:** иначе новые APK нельзя будет установить поверх существующих.

## Функциональность

Недельное расписание, ручной ввод нового кода перед каждым заказом, журнал заказов, встроенный браузер и диагностический режим. Работа с реальными финансовыми заказами экспериментальная.

При запуске обработки приложение пытается закрыть рекламное окно с изображением и открыть меню перед переходом к «Быстрому копированию». Поддерживаются кнопки закрытия и меню Vant, а также кнопки с доступными названиями «Закрыть» / «Close» и «Меню» / «Открыть меню» / «Menu» / «Open menu». Нажатие выполняется только при однозначном распознавании доступного элемента. Окна ввода кода, подтверждения и результата заказа автоматически как реклама не закрываются. После открытия меню приложение ждёт его содержимое, не нажимая кнопку повторно.

Вход в аккаунт и ввод нового динамического кода остаются ручными. Подготовка меню проверена автономными тестами; соответствие элементов настоящего сайта этим признакам требует проверки на устройстве.
